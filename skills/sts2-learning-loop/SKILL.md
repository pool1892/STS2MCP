# STS2 Learning Loop

Use this skill when the task is to turn gameplay into reusable improvement.

Read `../sts2-play/references/learning-loop.md` before updating run notes,
summarizing a fight, analyzing mistakes, or proposing future automation.

Record:

- the decision context, not just the outcome
- damage taken, missed lethal, and potion timing
- card reward choices and rejected alternatives
- API/state/action friction
- no-decision opportunities that should be removed from future reasoning
- concrete lessons that improve the next run
